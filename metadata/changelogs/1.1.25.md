# 1.1.25

## Features

- A Tomb of Peritia equipped in a Curios slot now stores incoming experience before it reaches the player's experience bar.
- Lex Vitae now uses Better Combat's one-handed sword moves when Better Combat is installed.

## Fixes

- Reduced Blood Lantern spawn-check overhead when no lanterns are nearby.
- Dungeon rituals now report the specific placement problem when they cannot form.
- Tree Feeling now replants saplings from its configured chest when harvested drops run out.
- Tree Feeling now reaches taller 2x2 spruce trees.
- Updated remaining guide references from Vas to Spiritus Crucible.
